# 🛡️ ChurnSight AI

## Plataforma de Inteligência de Retenção com IA

ChurnSight AI é uma plataforma completa de análise preditiva de churn desenvolvida para transformar dados de clientes em decisões executivas orientadas por inteligência artificial.

O projeto combina:

* Machine Learning preditivo
* Explainability com SHAP
* Simulações financeiras
* Engine analítica empresarial
* Geração narrativa com IA
* Relatórios executivos em PDF
* Dashboard interativo em Streamlit
